# Lucas Tao Portfolio

A cinematic, dependency-free portfolio for Lucas Tao, published with GitHub Pages at:

**https://lucaskazaki.github.io/**

## Portfolio focus

The site presents Lucas's work across:

- Machine learning and computer vision
- Robotics and autonomous systems
- Aerial perception and embedded AI
- Enterprise AI research and technical systems
- Science communication at the National Air and Space Museum
- Leadership in Terrapin Anime Society and QASA
- Ongoing explorations in agent systems, game technology, smart glasses, local AI infrastructure, and learning architectures

## Experience design

The page uses an original visual system built around four connected ideas:

**Sense · Reason · Act · Explain**

It includes:

- A responsive animated hero and technical orbit motif
- A sticky scroll narrative inspired by product storytelling
- Filterable project case studies with original inline SVG diagrams
- A professional experience timeline
- Leadership and event-impact metrics
- A curiosity lab for active explorations
- Education, skills, interests, and a printable resume view
- Accessible keyboard states and reduced-motion support

## Architecture

The production site is a self-contained static page with no framework, package manager, build step, analytics, or external JavaScript dependency. This makes GitHub Pages deployment fast and resilient.

Local preview:

```sh
python -m http.server 8080
```

Then open `http://127.0.0.1:8080`.

## Privacy and disclosure

The public portfolio intentionally omits street address, phone number, health information, family information, private correspondence, restricted datasets, confidential employer details, and private repository contents. Employer projects are described only at a sanitized, non-confidential level, and planned work is labeled as active exploration rather than completed production work.
