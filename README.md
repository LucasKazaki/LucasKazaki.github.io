# Lucas Tao — Portfolio

Static, dependency-free portfolio prepared for GitHub Pages.

## Local preview

```sh
python -m http.server 8080
```

Open `http://127.0.0.1:8080`.

## Deployment

The intended repository is `LucasKazaki/LucasKazaki.github.io`. GitHub Pages can publish directly from the repository root on the `main` branch.

## Privacy boundary

This public site intentionally excludes personal contact and identity records, academic records, application materials, private chat exports, employer-confidential materials, and restricted model/data assets.

## Future task: custom domain

Choose and register a personal domain, add a `CNAME` file containing the domain, configure GitHub Pages custom-domain settings, then enable HTTPS after DNS verification. Until then, use `https://lucaskazaki.github.io/`.
