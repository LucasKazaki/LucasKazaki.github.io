02 / Practice

How I approach technical work.

  1. 01

    Start from a falsifiable question.

    Define what should change, what evidence would count, and what would disprove the idea.

  2. 02

    Build the smallest visible system.

    Prefer an executable prototype and a measured baseline to an architecture that only exists on paper.

  3. 03

    Preserve the experiment.

    Record inputs, configurations, provenance, and known limitations so another person can inspect the result.
